# TimeShift

Помодоро-таймер для macOS, живущий в строке меню. Классический цикл 25/5/15 с ручным запуском этапов, ретро-логированием пропущенных промежутков и дневным «банком» перерывов.

## Возможности (v0.1)

- Таймер в трее (`🍅 24:31`) с меню: старт/пауза/смена этапа, парковка задач, глобальный хоткей `Cmd+Shift+Space`.
- Конечный автомат дня поверх журнала событий: любое действие валидируется, превращается в событие и применяется через свёртку (fold) — состояние всегда воспроизводимо из журнала.
- Ретро-разрывы: если между этапами прошло время, приложение предложит задним числом залогировать разрыв (`NeedGap`).
- WAL-first: события пишутся в JSONL-журнал (`~/.timeshift/wal/`) с fsync и ролловером по дням; Postgres не обязателен для работы таймера.
- Репликатор: WAL → Postgres (sqlx-миграции, идемпотентность через таблицу `applied_events`), переподключение с ретраями — Docker/БД могут быть недоступны, ничего не теряется.
- UI на React: экраны «День», «Парковка», «Настройки»; диалог разрыва с повтором исходной операции после ретро-логирования.

## Стек

- **Ядро:** Rust, Tauri 2
- **UI:** TypeScript, React, Vite
- **БД:** PostgreSQL 17 (опционально; без неё приложение работает на WAL)

## Установка

Готовые сборки macOS публикуются в [Releases](https://github.com/UnMatty/TimeShift/releases): скачайте `TimeShift_<версия>_universal.dmg` — универсальный образ и для Apple Silicon, и для Intel. Откройте его и перетащите приложение в Applications.

Приложение распространяется без подписи Apple, поэтому при первом запуске macOS может предупредить о неизвестном разработчике: нажмите на `TimeShift.app` правым кликом и выберите «Открыть».

Новый релиз собирается автоматически: workflow `.github/workflows/release.yml` срабатывает на пуш тега `v*` (или вручную из вкладки Actions) и публикует `.dmg` через [tauri-action](https://github.com/tauri-apps/tauri-action).

## Сборка и запуск

```bash
npm install
npm run tauri dev    # режим разработки
npm run tauri build  # сборка .app / .dmg
```

Тесты и линт ядра:

```bash
cd src-tauri
cargo test
cargo clippy
```

## Конфигурация

Конфиг лежит вне репозитория: `~/.timeshift/config.toml` (строка подключения к БД, настройки LLM-эндпоинта). Секреты (пароль БД, API-ключи) предполагается хранить в macOS Keychain — в репозитории и конфиге их нет.

## Архитектура

Ключевая идея: состояние дня — это свёртка журнала WAL-событий. Операции UI/трея не мутируют состояние напрямую, а валидируются и порождают события; запись в WAL и свёртка — единственный путь изменения состояния. Репликатор доносит журнал до Postgres, поэтому источник истины один — журнал.
